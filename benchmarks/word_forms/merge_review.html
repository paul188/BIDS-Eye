Word form joins

Should a search for one of these words also find the others?

Keys: 1–4 label and advance, ← →, N note. Sorted by how many datasets one spelling alone misses.

What the options mean

Join: same meaning; a search for any of them should find all.
Don't join: they mean different things here (e.g. "left" the side vs "leave"), or one is a name.
Only some: join part of the forms; write which in the note.
Unsure: can't tell from the forms and examples.

Each box is one stem as PostgreSQL sees it, with the forms the catalogue writes and how many datasets have each. Missed = datasets that write only the other spellings, i.e. what a search for this box alone loses today. Its stem also matches = words a search for this box already finds today through the shared stem. Labels are kept in this browser; export them, the file is what counts. Set merge-b2255a82eb55.
